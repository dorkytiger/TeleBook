# TeleBook 4.0：全新升级的跨平台图书管理与阅读应用

**TeleBook** 是一个使用 **Flutter** 开发的功能强大的跨平台图书解析、管理与阅读应用。支持多种导入方式、智能书库管理、个性化阅读体验、**多设备同步**，让数字阅读变得前所未有的便捷和舒适。

## ✨ 4.0 版本重大更新：同步引擎重构 + 真正后台同步 + 诊断系统

### 🔄 同步任务队列（一切同步动作统一为"组任务"）

- **统一任务模型**：初始化 / 刷新 / 上传快照 / 手动同步 / 冲突解决 / 恢复上次同步 / 本地变更推送，全部进入同一组任务队列串行执行
- **任务中心页**：队列列表 → 任务详情 → 每本书 → 每张图片，三级状态全可见；失败原因直接展示，可**整批重试 / 单本重试 / 单页重试**
- **全局统一底栏状态条**（单一来源）：当前任务（第X/共N本 · 页a/b）/ 待解决冲突 / 失败任务，右侧「查看」直达任务中心
- **本地同步记录**：任务历史按队列时间排列，失败/中断的任务可展开明细并原地重试（复用原任务行，不留残影）

### 🔄 断点续传与中断恢复

- **真正断点续传**：任务中断（App 被杀 / 网络断开）后重启，自动把遗留任务标记为中断；用户确认后**按落库的任务规格原地恢复**，已完成的书/页自动跳过，不重复传输、不产生多余历史行
- **失败隔离**：单本书 / 单张图片失败不影响同批其它任务；失败页状态回退为等待，重试不残留半截文件

### 🛡️ 冲突解决流程化

- 双向同步发现内容冲突 → 冲突列表 → 逐个选择「保留服务器」或「保留本地」
- 解决动作本身作为组任务执行并写入本地记录，全程可见、可重试

### 📱 iOS：真正的后台下载与上传（原生 URLSession）

- **原生后台队列**：整本书的图片一次性交给系统 URLSession background session，原生内部限并发、完成自动派发下一个——**App 锁屏 / 挂起 / 被系统回收后，批次仍由系统持续推进**（不再依赖 Dart 进程存活）
- **杀进程恢复**：每个任务的目标路径编码进请求，App 被回收重启后由系统唤醒补落盘
- **后台直传**：新增服务器整文件直传接口（PUT 原始字节，内容寻址幂等），失败自动回退分片上传

### 🤖 Android：前台服务保活

- 同步期间启动前台服务（常驻通知 + 部分唤醒锁），熄屏 / 切后台不断网，任务稳定跑完

### 🐛 图片顺序修复

- 修复多次重试下载后图片页序被打乱的问题：服务器按上传顺序落库、客户端按清单顺序建库，任何重试路径都不再改写页序

### 🧰 诊断与日志系统（崩溃可追查）

- **统一日志器**：控制台 + 滚动落盘（{appDocDir}/logs/app.log）+ 内存环形缓冲（崩溃前 200 行现场）
- **崩溃自动捕获**：Dart 层错误（FlutterError / async / Zone）自动落盘为崩溃记录，含设备型号、系统版本、App 版本、服务器地址（脱敏）与崩溃前现场
- **日志健壮性**：单文件 2MB 滚动 × 4、目录总量预算、30 分钟定时清理、崩溃记录保留 10 份且超 30 天清理、写盘失败自动冷却自愈、旧版日志自动迁移
- **设置 → 调试**：「诊断日志」实时查看页 + 「导出诊断包」一键打包（日志 + 崩溃记录 + 设备信息）通过系统分享发出，配合关键节点埋点（启动 / DB 升级 / 同步 / 前后台切换），让他人应用崩溃也能快速定位

## ✨ 3.1 版本新增：多设备同步（历史）

### 🔄 本地优先（离线优先）

- **离线可用**：所有变更（导入 / 修改 / 删除 / 阅读进度）立即在本地生效，同时写入待同步队列，后台自动推送
- **断网不中断**：无网络时正常使用，恢复网络后自动补齐同步
- **底栏状态条**：冲突 > 手动同步进度 > 同步中 > 待同步 N（点击立即同步）

### 🌐 整库同步

- **书籍与图片**：书籍信息、阅读进度、全部图片文件跨设备一致
- **连接即同步**：新设备"保存并连接"后自动下载全部书籍，逐本显示图片下载进度
- **文件内容寻址**：图片按 SHA-256 去重分片上传，重复内容不重复传输

### 📚 整库快照历史

- 敏感操作（导入 / 修改 / 删除 / 手动同步）完成后自动归档整库快照
- 可查看历史列表，一键恢复到归档时刻（整库替换）

### 📋 本地同步记录

- 每次同步会话：时间 / 书籍数 / 状态
- 展开每本书：上传 / 下载状态
- 展开每张图片：上传 / 下载进度

### 🛡️ 冲突处理

- 多设备同时修改同一本书时自动检测冲突
- 弹层选择：保留本地 / 保留服务器 / 手动合并（支持批量勾选）

### 📍 阅读进度同步

- 翻页自动保存（防抖 800ms），另一台设备打开同一本书恢复到上次阅读位置
- 高频操作自动合并，不产生海量同步任务

### 方式二：手动编译

```bash
# 克隆项目
git clone https://github.com/dorkytiger/TeleBook.git
cd TeleBook

# 安装依赖
flutter pub get

# 生成代码（Drift 数据库）
flutter pub run build_runner build --delete-conflicting-outputs

# 编译
flutter build apk        # Android
flutter build ios        # iOS
flutter build windows    # Windows
flutter build macos      # macOS
```

## 🚀 快速开始

### 📖 导入你的第一本书

#### 方式一：通过网页链接解析

1. **复制书籍链接** - 在 Telegraph 或其他网页找到想要的书籍，复制链接地址
2. **打开导入界面** - 点击右上角的 ➕ 号
3. **选择网页数据源** - 选择"网页"，粘贴链接到"网址"字段
4. **解析并预览** - 应用自动加载网页并提取图片，实时预览
5. **添加到下载队列** - 点击"保存"按钮，图片将被添加到下载队列
6. **保存书籍** - 下载完成后，点击"保存书籍"将书籍添加到书架

#### 方式二：通过压缩包导入

1. **准备压缩包** - 将图片文件打包成 ZIP、CBZ 或其他压缩格式
2. **选择压缩包数据源** - 点击 ➕ 号，选择"压缩包"
3. **选择文件** - 点击"选择文件"，从设备中选择压缩包
4. **自动解压** - 应用自动解压并识别图片，点击"保存"添加到书架

#### 方式三：批量压缩包导入

1. **准备文件夹** - 将多个 ZIP/CBZ 文件放在同一文件夹
2. **选择批量数据源** - 选择"批量压缩包"
3. **选择文件夹** - 选择包含压缩包的文件夹
4. **编辑文件列表** - 可选择性编辑每个压缩包的文件顺序
5. **批量导入** - 点击 ✅ 按钮批量保存所有书籍

### 📚 管理你的书库

#### 创建收藏夹

1. **进入收藏夹管理** - 在书籍列表页面，点击右上角三点菜单 → "收藏夹管理"
2. **新建收藏夹** - 点击 ➕ 按钮，输入名称、选择图标和颜色
3. **添加书籍到收藏夹** - 长按书籍选择"加入到收藏夹"，或使用批量操作

#### 使用标签系统

1. **创建标签** - 在"书签管理"页面创建不同颜色的标签
2. **为书籍添加标签** - 在书籍操作菜单中选择"添加书签"
3. **按标签筛选** - 在书籍列表使用筛选功能按标签查看书籍

#### 切换显示布局

- 在书籍列表页面，点击筛选按钮可以切换列表视图和网格视图

### 📖 个性化阅读设置

#### 设置阅读方向

1. **打开阅读设置** - 在阅读页面点击右上角设置图标
2. **选择阅读方向**：
    - **从左往右**：适合大多数书籍和漫画
    - **从右往左**：适合日式漫画
    - **从上往下**：适合长条漫画，图片连续滚动显示
3. **设置自动保存** - 选择后设置立即保存，下次自动应用

#### 阅读进度记录

- 应用自动记录每本书的阅读位置
- 重新打开书籍时自动跳转到上次阅读位置
- 在书籍列表中可看到每本书的阅读进度条

## 🔄 多设备同步配置

1. **部署后端**：克隆 [TelebookServer](https://github.com/dorkytiger/TelebookServer)，`cp .env.example .env` 配置密钥后 `docker compose up --build`
2. **手机 A 连接**：设置 → 同步服务器 → 填写服务器地址（如 `http://192.168.x.x:18080`）与连接密钥 → 保存并连接，自动上传书库与图片
3. **手机 B 连接**：同样操作，自动下载全部书籍与图片
4. **持续同步**：任一侧导入 / 修改 / 删除 / 阅读，另一侧自动同步；离线操作不阻塞，联网自动补齐
